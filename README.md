# 🍽️ Bengaluru Zomato Restaurant Analytics

An end-to-end **Data Analytics and Business Intelligence** project using **Python, SQL, and Power BI** to analyze restaurant performance and customer-facing attributes across Bengaluru.

## 🎯 Business Objective

The goal is to understand restaurant distribution, customer engagement, ratings, pricing, online-order availability, table booking, restaurant types, and cuisine patterns to support data-driven decisions.

## 🧰 Tools & Technologies

- **Python:** Pandas, NumPy, Matplotlib
- **SQL:** Aggregations, JOINs, CTEs, window functions, filtering
- **Power BI:** Power Query, data modeling, DAX, KPI development, interactive visualization
- **Excel:** Source data preparation

## 🔄 Project Workflow

1. **Data Preparation** – reviewed the restaurant dataset and selected relevant analytical fields.
2. **Data Cleaning** – handled missing values, converted ratings/cost/votes into analytical formats, and removed duplicate restaurant records.
3. **Exploratory Analysis** – analyzed locations, restaurant types, ratings, votes, cuisines, pricing, online orders, and table booking.
4. **SQL Analysis** – created business-oriented queries for restaurant counts, ratings, customer engagement, and ordering behavior.
5. **Power BI Dashboard** – developed an interactive Bengaluru Restaurant Analytics dashboard with KPIs and visual analysis.

## 📊 Key Business Questions

- Which Bengaluru locations have the highest restaurant concentration?
- Which restaurant types receive the strongest ratings and customer engagement?
- How common are online orders and table bookings?
- Which restaurants have high ratings combined with strong vote volume?
- How does approximate cost vary across restaurant categories?
- What cuisine patterns appear most frequently?
