# Data Dictionary

| Column | Description |
|---|---|
| name | Restaurant name |
| online_order | Whether online ordering is available |
| book_table | Whether table booking is available |
| rate | Restaurant rating as provided in the source |
| votes | Number of votes/reviews |
| location | Bengaluru locality |
| rest_type | Restaurant type |
| dish_liked | Popular dishes reported in the source |
| cuisines | Cuisine categories |
| approx_cost(for two people) | Approximate cost for two people |
| listed_in(type) | Listing/category type |
| listed_in(city) | City/listing grouping |
